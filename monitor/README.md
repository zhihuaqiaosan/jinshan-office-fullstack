## 开发中遇到的问题及解决方案

### 问题1：HTTP和TCP探测的统一抽象

**问题描述**：需要同时支持HTTP和TCP两种协议的探测，且探测逻辑不同。

**解决方案**：在`probe.go`中实现`probeHTTP`和`probeTCP`两个方法，在`probeTarget`中根据地址前缀（http://或https://）判断使用哪种探测方式。

### 问题2：重试机制的实现

**问题描述**：需要支持可配置重试次数，且重试次数不超过3次。

**解决方案**：在`probeTarget`函数中使用循环实现重试逻辑，每次尝试都独立执行探测。在配置加载时对`retry_count`进行校验，超过3的自动限制为3。

### 问题3：并发结果收集的数据竞争

**问题描述**：多个goroutine同时写入结果可能造成数据竞争。

**解决方案**：使用Go的channel作为结果收集通道，每个探测任务完成后将结果发送到channel，主goroutine从channel中读取并聚合结果。

### 问题4：慢速服务阻塞问题

**问题描述**：某些服务响应慢（如httpbin.org/delay/5）会阻塞整个探测流程。

**解决方案**：使用context.WithTimeout为每个探测任务设置独立的超时控制，超时后自动取消请求。

### 问题5：人为延迟不影响并发性能

**问题描述**：需要在代码中人为加入1秒延迟来展示并发性能，但不能影响整体的并发执行。

**解决方案**：在`Run`方法开始时统一添加`time.Sleep(1 * time.Second)`，由于所有goroutine几乎同时启动，这个延迟只影响启动时间，不影响并发效果。
