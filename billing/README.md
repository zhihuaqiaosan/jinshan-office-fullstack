## 二、关键逻辑实现思路

1. **阶梯电费计算**：采用分段累加法，根据用电量所在档位，分别计算各档费用后求和。

2. **峰谷调节**：使用 `time.Parse()` 解析时间字符串，提取小时数判断属于高峰时段（8:00-22:00）还是低谷时段，返回对应调节因子（1.1或0.8），最终电费 = 阶梯电费 × 调节因子。

3. **异常处理**：时间解析失败时打印提示信息，默认返回高峰因子（1.1），保证程序正常运行。

## 五、跨阶梯计费逻辑难点

### 难点描述

当用户用电量跨越多个阶梯时（如450度：200度第一档 + 200度第二档 + 50度第三档），不能简单用总电量乘以单价，必须分段计算每个阶梯的费用再累加。

### 解决方案

采用 `if-else` 分支结构分段累加：

```go
if electricity <= 200 {
    return electricity * 0.5
} else if electricity <= 400 {
    return 200*0.5 + (electricity-200)*0.8
} else {
    return 200*0.5 + 200*0.8 + (electricity-400)*1.2
}
