| **HTTP 请求**     | Axios                       | 请求拦截、响应拦截   |
| **Markdown 渲染** | react-markdown + remark-gfm | 支持表格和GFM语法    |

### 3.2 关键逻辑实现思路

#### 3.2.1 认证与路由守卫

```typescript
// 核心思路：检查 localStorage 中的 token，无 token 则重定向到登录页
useEffect(() => {
  const token = localStorage.getItem('token');
  if (token) {
    setIsAuthenticated(true);
  }
  setLoading(false);
}, []);

// 路由配置：未认证访问根路径自动跳转 /login
<Route path="/" element={
  isAuthenticated ? <Layout /> : <Navigate to="/login" replace />
} />
